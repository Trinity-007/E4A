API Documentation

Base URL: https://e4a.com/api/seller

Authentication: Include your API key in the x-api-key header

curl -H "x-api-key: YOUR_API_KEY_HERE" https://e4a.com/api/seller/products

Endpoints

GET /products

Get all your products

curl -H "x-api-key: YOUR_KEY" https://e4a.com/api/seller/products

Response: List of products with name, price, category, description

GET /orders

Get orders for your products

curl -H "x-api-key: YOUR_KEY" https://e4a.com/api/seller/orders

Response: List of orders containing your products

PUT /products/:productId

Update a product listing

curl -X PUT -H "x-api-key: YOUR_KEY" -H "Content-Type: application/json" \ -d '{"name":"New Name", "price": 99}' \ https://e4a.com/api/seller/products/PRODUCT_ID

Body: { name, price, description, image }

POST /keys

Generate a new API key (admin only)

curl -X POST -H "Content-Type: application/json" \ -d '{"sellerId":"YOUR_ID", "keyName":"My Key"}' \ https://e4a.com/api/seller/keys

Integration Examples

JavaScript/Node.js

const apiKey = 'your-api-key-here'; // Get all products fetch('https://e4a.com/api/seller/products', { headers: { 'x-api-key': apiKey } }) .then(res => res.json()) .then(data => console.log('Products:', data.products));

Python

import requests headers = {'x-api-key': 'your-api-key-here'} response = requests.get('https://e4a.com/api/seller/products', headers=headers) products = response.json() print(products)

PHP

$ch = curl_init(); curl_setopt($ch, CURLOPT_URL, 'https://e4a.com/api/seller/products'); curl_setopt($ch, CURLOPT_HTTPHEADER, ['x-api-key: your-api-key-here']); curl_setopt($ch, CURLOPT_RETURNTRANSFER, true); $response = curl_exec($ch); $products = json_decode($response, true); echo json_encode($products);
