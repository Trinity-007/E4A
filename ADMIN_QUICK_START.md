## 🎯 Common Tasks

### Task 1: Monitor Marketplace
1. Login to admin panel
2. Click "📈 Dashboard"
3. See real-time statistics:
   - Total users
   - Total products
   - Total orders
   - Pending verifications
4. View recent activity

### Task 2: Delete a Spammer Account
1. Click "👥 Users"
2. Find user in list
3. Click "Delete" button
4. Confirm deletion

### Task 3: Update Order Status
1. Click "📦 Orders"
2. Find order in list
3. Click "Update"
4. Enter new status (pending/processing/shipped/delivered)
5. Status updates immediately

### Task 4: Approve a Seller
1. Click "✅ Verifications"
2. Review pending verifications
3. Click "Approve" to accept
4. Seller is now verified

### Task 5: Remove a Banned Product
1. Click "🏪 Products"
2. Find product in list
3. Click "Delete"
4. Confirm removal
